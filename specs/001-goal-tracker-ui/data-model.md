# Data Model: DoIt — Initial Page Setup

## Goal

The single domain entity. Stored as a JSON object in the `doit:goals` localStorage array.

```typescript
// lib/types.ts

export type GoalStatus = 'active' | 'completed';

export interface Goal {
  /** Unique identifier — crypto.randomUUID() at creation time */
  id: string;

  /** User-provided title. Non-empty string. Max display: wraps; no hard cap enforced. */
  title: string;

  /**
   * End date as ISO-8601 date string (YYYY-MM-DD).
   * Must be >= today at creation time.
   * Time component intentionally omitted — day-level granularity only.
   */
  endDate: string;

  /** Lifecycle status. Toggled by checkbox. Never goes back to 'active' once 'completed'. */
  status: GoalStatus;

  /**
   * Creation timestamp as ISO-8601 string.
   * Set once at creation; never mutated.
   * Used for stable insertion-order sorting within a column.
   */
  createdAt: string;
}
```

### Derived / Computed Properties

These are NOT stored — computed on render from `endDate` and current date:

| Derived Field | Type | Logic |
|---------------|------|-------|
| `daysRemaining` | `number` | `differenceInCalendarDays(parseISO(endDate), startOfDay(new Date()))` |
| `isDueSoon` | `boolean` | `daysRemaining >= 0 && daysRemaining <= 3` |
| `isOverdue` | `boolean` | `daysRemaining < 0` (past due, still active) |

### Validation Rules

| Field | Rule |
|-------|------|
| `title` | Required; non-empty after trim |
| `endDate` | Required; must be today or a future date (validated against `startOfDay(new Date())`) |
| `status` | Must be `'active'` on creation; transitions to `'completed'` on checkbox |
| `id` | Generated by `crypto.randomUUID()`; never user-supplied |

### State Transitions

```
          [ User creates goal ]
                  │
                  ▼
             ┌─────────┐
             │  active │ ◄── Initial state
             └─────────┘
                  │ checkbox checked
                  ▼
           ┌───────────┐
           │ completed │  (no reverse transition in v1)
           └───────────┘
                  │ delete confirmed
                  ▼
             [ removed ]

    active ──────────────────── delete confirmed ──► [ removed ]
```

## localStorage Schema

**Key**: `doit:goals`
**Value**: JSON-serialised `Goal[]`

```json
[
  {
    "id": "b3f2c1d4-...",
    "title": "Learn TypeScript generics",
    "endDate": "2026-05-20",
    "status": "active",
    "createdAt": "2026-05-12T07:00:00.000Z"
  },
  {
    "id": "a1e9d7c2-...",
    "title": "Finish project spec",
    "endDate": "2026-05-14",
    "status": "active",
    "createdAt": "2026-05-11T14:30:00.000Z"
  }
]
```

### Storage Helpers (`lib/storage.ts`)

```typescript
const STORAGE_KEY = 'doit:goals';

loadGoals(): Goal[]          // JSON.parse with fallback to []
saveGoals(goals: Goal[]): void  // JSON.stringify + localStorage.setItem
```

### SSR Guard

All `localStorage` access MUST occur inside `useEffect` or behind:
```typescript
if (typeof window === 'undefined') return [];
```
This prevents Next.js server-render hydration errors.

## View Collections (derived, not stored)

| View | Filter | Sort |
|------|--------|------|
| Active Goals | `status === 'active'` | `createdAt` ascending (oldest first) |
| Completed Goals | `status === 'completed'` | `createdAt` descending (most recently completed at top) |
